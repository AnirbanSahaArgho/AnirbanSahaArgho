## Local-first implementation

Everything in this profile is intended to be self-contained:

- SVG cards contain their own CSS, SMIL animation, image data, and embedded WOFF2 fonts.
- No JavaScript is required.
- No remote font, image, CDN, or icon request is required by the SVG assets.
- `?v=1` cache-busters are included on every README image reference.
- The design uses a midnight-glass palette with cyan → violet → pink aurora accents.
